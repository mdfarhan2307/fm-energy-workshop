# FM Energy Workshop

A workshop prototype for building electricity consumption forecasting.

## Goal

Predict the next hour's electricity consumption for a building and display the forecast on a live dashboard.

## Planned Tools

- **Python** — data processing and forecasting model
- **Streamlit** — interactive dashboard
- **Neon Postgres** — cloud database for storing consumption data and predictions

## Status

This project is a workshop prototype and is not intended for production use.
